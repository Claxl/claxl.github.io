I help run our FPGA101 course at NECSTLab, which walks students through the
full HLS-to-PYNQ design flow on the **Ultra96** board. The course covers:

- HLS optimization with diff-style progressions on histogram and FIR filters.
- Vivado block-design for Zynq UltraScale+, including AXI SmartConnect
  address-width quirks.
- PYNQ host code with 64-bit address handling.
- Jupyter notebooks for each lesson, with visualizers that compare HLS
  variants side-by-side.
